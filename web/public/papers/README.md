# Example papers

Third-party paper PDFs are not bundled without confirmed redistribution rights.
The previous FlowDyn example is available from its publication page:
https://arxiv.org/abs/1910.03324

Obtain a permitted copy separately and upload it through the document interface.
Do not commit private papers or assume that freely downloadable means freely
redistributable. This removal affects the current tree only, not Git history,
old refs, Actions artifacts, or previously built images.
